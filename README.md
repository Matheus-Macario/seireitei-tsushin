# seireitei-tsushin


Site de notícias fictício, no formato de boletim oficial da 9ª Divisão do Gotei 13, ambientado no universo de Bleach. Projeto de fã, sem fins comerciais, que começou como atividade da disciplina de Desenvolvimento Web (ADS, FATEC Sorocaba) e continua em desenvolvimento.

# Aviso de spoilers: as notícias abordam acontecimentos da Saga Soul Society e futuramente de outros acontecimentos.


Sobre o projeto:

O site simula as edições do jornal da 9ª Divisão: uma página inicial com as manchetes e uma página para cada notícia, incluindo uma edição extra com visual de destaque. O foco do projeto é praticar HTML e CSS na construção de um site de várias páginas, com atenção a responsividade e acessibilidade.

Funcionalidades:
Site multipágina, com navegação entre a página inicial e as notícias.
Layout responsivo com CSS Grid, Flexbox e media queries.
Modo escuro automático, com base na preferência do sistema (prefers-color-scheme).
Cores e estilos centralizados em variáveis CSS.
HTML semântico, atributo lang e rótulos de acessibilidade (aria-label).
Tipografia com as fontes Shippori Mincho e Zen Kaku Gothic New, via Google Fonts.

Tecnologias:

HTML5,
CSS3

Estrutura:
seireitei-tsushin/

├── Seireitei-Tsūshin-Principal (Seireitei Tsūshin apenas no V1).html       # página inicial com as manchetes
